# Command icon resources

Fusion loads `16x16.png`, `32x32.png`, and `64x64.png` for the Create Drill
Bit Bins toolbar command.

The icon retains the isometric blue-bin silhouette of the upstream
FusionGridfinityGenerator command icon and adds a bold charcoal twist drill
bit and holder openings. It was created as a transparent high-resolution edit,
then cropped and downsampled for toolbar legibility.

`source/upstream-gridfinity-bin-64x64.png` is the upstream reference image.
`source/drill-bit-holder-master.png` is the generated transparent master used
for the three final sizes. Attribution and licensing are documented in
`../../../THIRD_PARTY_NOTICES.md` and `../../../LICENSE.md`.
