# Vendored Gridfinity geometry

These modules are an intentionally limited extraction of Lev Mishin's
FusionGridfinityGenerator. They are pinned to upstream revision `8a113b9` and
are used to create this add-in's solid base bin directly, without requiring a
second Fusion add-in or a custom-event API modification.

See `../../THIRD_PARTY_NOTICES.md` and `../../LICENSE.md` for attribution, the
upstream link, modification notes, and licence terms. The upstream files are
excluded from local formatting and lint rewrites so future source updates
remain reviewable.
